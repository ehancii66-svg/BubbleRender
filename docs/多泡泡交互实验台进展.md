# 多泡泡交互实验台进展

本文档记录从最近一次 Git 提交 `0b9576c 添加多泡泡交互论文资料` 之后，到当前版本为止，Windows OpenGL 实验端在多泡泡交互、生成控制、风场控制和泡泡软壳形变方面的新增实现。

## 目标

这一阶段的目标不是继续重构多泡泡接触拓扑，而是先把 Windows 端做成一个更好用的“多泡泡交互实验台”：

- 可以生成不同大小的泡泡；
- 可以控制生成位置和生成深度；
- 可以限制最多生成数量；
- 可以控制风向，让泡泡在风中自然移动和碰撞；
- 泡泡在非接触状态下也能产生轻微非球形软壳形变；
- 终端输出保持简洁，避免运行时持续刷屏。

这些能力用于后续稳定复现不同碰撞场景，再继续优化大/小泡接触、多泡泡融合和共享膜拓扑。

## 统一泡泡生成入口

新增了 `BubbleSpawnRequest` 和 `SpawnBubble(...)`，用于统一所有动态泡泡生成逻辑。

当前生成请求包含：

- `position`：泡泡初始中心位置；
- `basePosition`：漂浮/回拉的参考位置；
- `initialVelocity`：初始速度；
- `radius`：生成半径；
- `shapePerturbation`：初始软壳扰动强度；
- `filmThickness`：薄膜厚度缩放；
- `phase`：随机/周期运动相位；
- `windAmplitude`、`floatAmplitude`、`speed`：视觉漂浮参数。

这样 `B` 键自动生成、`Shift + 左键` 鼠标生成，以及后续 HarmonyOS 触摸生成，都可以走同一个 seam。

## 生成数量控制

原来只有固定硬上限，现在拆成两层：

- `kHardMaxDisplayBubbleCount = 16`：硬上限，保护模型数量和渲染资源；
- `g_MaxLiveBubbleCount = 8`：运行时可调 live 泡泡上限。

交互：

- `,`：减少最多 live 泡泡数；
- `.`：增加最多 live 泡泡数。

运行时上限最低不会低于默认三泡泡数量，最高不会超过硬上限 16。

## 生成大小控制

新增当前生成半径：

- `g_SpawnRadius = 0.40`
- 最小：`0.22`
- 最大：`0.72`

交互：

- `[`：减小后续生成泡泡半径；
- `]`：增大后续生成泡泡半径。

`B` 键自动生成和 `Shift + 左键` 鼠标生成都会使用当前 `g_SpawnRadius`。

## 鼠标定点生成与生成深度

新增屏幕点投射生成：

1. 从当前相机对鼠标屏幕点发射 ray；
2. 与当前生成平面求交；
3. 在交点生成新泡泡。

交互：

- `Shift + 左键`：在鼠标指向的当前生成平面上生成泡泡；
- 普通左键仍然用于旋转相机。

生成平面从固定常量升级为可调变量：

- 默认深度：`g_BubbleSpawnPlaneZ = 1.10`
- 范围：`0.25 ~ 2.60`
- 步长：`0.12`

交互：

- 普通滚轮：缩放相机；
- `Shift + 滚轮`：调整泡泡生成深度。

目前这个深度是世界坐标中的 `Z` 平面深度，不是沿相机视线方向的距离。如果后续觉得视觉上不够直观，可以升级为 camera-space spawn distance，或者增加生成预览。

## 全局风场交互

新增全局风状态：

- `g_WindEnabled`：是否启用全局风；
- `g_GlobalWindDirection`：全局风向；
- `g_GlobalWindStrength`：全局风强度，目前固定为 `0.16`。

交互：

- `F`：开关全局风；
- `I`：风向向上；
- `J`：风向向左；
- `K`：风向向下；
- `L`：风向向右。

为了避免键位冲突，同步调整了原有按键：

- 接触 replay demo 从 `I` 改为 `G`；
- 薄膜干涉模式切换从 `L` 改为 `;`；
- 边缘畸变增强从 `J` 改为 `8`，即 `U / 8` 控制减小/增大。

全局风已经接入泡泡中心运动，不再只是视觉摆动。小泡泡由于半径响应权重更高，会更容易被风推动；大泡泡更稳定。

## 风驱动软壳形变

这一版开始让泡泡在非接触状态下也不是完全球形。

实现位置在 `UpdatePersistentSurfaceDynamics(...)`：

- 每个泡泡已有的 `surfaceControls` 会生成一个目标位移；
- 目标位移由自由波动、当前速度和全局风方向共同决定；
- 通过弹簧阻尼更新 `control.displacement` 和 `control.velocity`；
- 顶点生成阶段继续从这些控制点采样位移。

形变主要包括：

- 沿风/速度方向的低阶椭球形变；
- 迎风面轻微内凹；
- 背风面轻微拖尾；
- 侧向轻微波动；
- 小泡更活跃，大泡更稳定。

接触形变仍然叠加在同一套 `surfaceControls` 上，因此风形变和接触形变可以连续共存。

## 大小不同泡泡的当前交互逻辑

当前大泡/小泡接触仍沿用 pair-wise 接触系统：

- 接触距离按 `dist <= rA + rB` 附近判断；
- 共享膜半径主要由 `min(rA, rB)` 决定，避免膜尺寸超过小泡承受尺度；
- 泡泡质量按体积近似，`mass ∝ radius^3`；
- 小泡更容易被风和碰撞带动，大泡中心运动更稳定；
- 共享膜曲率使用简化的 `1 / rA - 1 / rB` 关系，表达大小不同导致的膜弯曲趋势。

需要注意的是，当前 `Merged` 仍是视觉/状态阶段，不是两个泡泡拓扑上真正合成一个物理对象。两个泡泡仍然各自保留中心、半径和 shell，只是通过 `BubbleContactPair` 共享接触膜和局部形变。

## 终端输出优化

之前 `[BubbleContact]` 每秒输出接触状态，会在正常运行时刷屏。

当前新增：

- `g_LogContactDebug = false`
- `C`：开关 contact debug log

默认运行时只输出启动信息和用户按键触发的状态变化。只有按 `C` 打开后，才会每秒输出接触 pair 的调试数据。

## 当前主要交互汇总

- 左键拖拽：旋转相机；
- 右键拖拽：触摸涟漪；
- 滚轮：缩放相机；
- `Shift + 滚轮`：调整泡泡生成深度；
- `Shift + 左键`：在当前生成深度平面生成泡泡；
- `B`：自动新增泡泡；
- `V`：删除最后一个动态泡泡；
- `[` / `]`：调整新泡泡半径；
- `,` / `.`：调整最多 live 泡泡数；
- `F`：开关全局风；
- `I / J / K / L`：风向上/左/下/右；
- `C`：开关接触调试日志；
- `G`：重放双泡接触 demo；
- `;`：切换薄膜干涉模式；
- `U / 8`：调节边缘畸变。

## 已验证

每次阶段性修改后均进行了 Windows Release 构建验证：

```powershell
cmd /d /s /c "call D:\vs2022\VC\Auxiliary\Build\vcvars64.bat >nul && cmake --build build-ninja --config Release"
```

当前版本也进行了短运行验证：

- `BubbleRender.exe` 可以正常启动；
- 主循环持续运行；
- 默认不再持续刷接触日志；
- 程序由测试脚本主动停止。

构建过程中仍有 MSVC `C4819` 编码警告，这是项目已有的中文/特殊字符编码警告，不影响本次功能运行。

## 后续建议

下一步交互侧可以继续做：

- 屏幕 HUD，显示当前半径、生成深度、风向、风开关、live 数量；
- 生成位置预览，显示当前鼠标对应的生成点和半径；
- 风强度调节；
- 清空动态泡泡；
- 暂停时单步推进。

接触/形变侧可以继续做：

- 强化大小不同泡泡接触时的小泡变形、大泡稳定；
- 更明显的共享膜弯曲；
- 多接触情况下的 contact graph；
- 后续 Plateau junction 或统一泡沫网格。
