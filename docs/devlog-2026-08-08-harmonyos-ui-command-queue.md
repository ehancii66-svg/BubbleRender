# 鸿蒙交互命令队列优化记录

## 背景

鸿蒙界面的按钮事件、手势事件和 native 渲染帧此前都在同一 ArkTS/UI 线程上同步执行。场景重置、演示切换、添加泡泡和破裂泡泡会在点击回调内直接创建或删除网格、重置模拟状态，因此部分点击需要等待较长时间才显示反馈。

## 本次修改

在 `refraction/entry/src/main/cpp/napi_init.cpp` 中增加了 native UI 命令队列。

- 场景重置、演示切换、添加泡泡和破裂泡泡改为只写入轻量命令。
- `renderFrame()` 在帧开始时最多消费一个命令，避免同一帧叠加多个场景重建或网格创建操作。
- 添加操作保存世界坐标和半径；破裂操作先完成轻量拾取，再延后执行破裂初始化。
- 演示切换保存目标演示编号，连续点击不会因异步执行顺序而跳错状态。
- 相机旋转、双指缩放、风向、风力和滑条参数仍是即时更新，因为它们只修改少量标量状态。

## 效果与边界

按钮和手势回调不再直接承担模型创建、DBSTT 破裂初始化或场景清空工作，界面状态可以先反馈。每个重操作仍会在后续某一个渲染帧完成，因此添加、破裂和场景切换在执行帧仍可能产生一次短暂的画面波动；后续可继续把网格创建拆分到 worker 或按帧分块上传。

## 真机验证

2026-08-08 在已连接鸿蒙真机上覆盖安装 signed HAP 并启动验证：

- native graphics 初始化成功；
- 薄膜 LUT 与 FBO 创建成功；
- 初始小泡泡与大泡泡融合对持续推进；
- 未出现 shader 编译失败或黑屏。
