# BubbleRender 多泡泡交互与操作说明

本文档记录当前 Windows OpenGL 实验端已经实现的操作方式、多泡泡接触结果、融合流程和主要代码结构。内容对应当前 `main` 分支工作区实现。

## 1. 当前功能概览

当前版本支持：

- 创建不同尺寸的动态泡泡；
- 在鼠标位置预览并生成泡泡；
- 调整生成半径、生成深度和最大泡泡数量；
- 开关全局风，调整风速与风向；
- 无风时进行有界的低频随机摆动；
- 泡泡接近、接触、形成共享膜；
- 根据泡泡相对尺寸和接触状态选择分离、稳定 8 字双泡或融合；
- 展示等尺寸稳定双泡、小泡泡并入大泡泡、接触后分离三种场景；
- 保持融合前后薄膜参数、颜色和融合表面的连续性。

程序启动后默认进入双泡交互展示。全局风默认关闭。

## 2. 构建与运行

在项目根目录执行 Release 构建：

```powershell
cmd /c "call D:\vs2022\Common7\Tools\VsDevCmd.bat -arch=x64 -host_arch=x64 >nul && cmake --build windows\build-ninja --config Release"
```

可执行文件位于：

```text
windows/build-ninja/BubbleRender.exe
```

## 3. 视角和鼠标操作

| 操作 | 功能 |
| --- | --- |
| 左键拖动 | 旋转相机 |
| 右键按下或拖动 | 对泡泡施加触摸涟漪 |
| 鼠标滚轮 | 相机缩放 |
| 按住 `Shift` | 在鼠标位置显示半透明生成预览 |
| `Shift + 鼠标滚轮` | 调整泡泡生成平面的 Z 深度 |
| `Shift + 左键` | 在当前预览位置生成泡泡 |
| `Shift + 右键` | 删除鼠标所指的泡泡 |

生成预览使用当前生成半径和生成深度。预览只用于定位，不会提前加入物理或接触计算。

## 4. 添加、删除和调整泡泡

### 4.1 添加泡泡

当前只保留一种添加方式：

- `Shift + 左键`：在鼠标对应的生成平面位置精确生成泡泡。

新泡泡通过统一的 `BubbleSpawnRequest` 和 `SpawnBubble(...)` 入口创建，并使用当前的生成半径。

### 4.2 预览生成位置

按住 `Shift` 后，鼠标位置会显示一个低透明度泡泡预览：

1. 从相机经过鼠标位置发射射线；
2. 射线与当前 Z 生成平面求交；
3. 在交点绘制预览；
4. 按下左键后在同一位置创建真实泡泡。

### 4.3 控制生成大小

| 按键 | 功能 |
| --- | --- |
| `[` | 生成半径减小 `0.03` |
| `]` | 生成半径增大 `0.03` |

当前范围：

```text
最小半径：0.22
默认半径：0.40
最大半径：0.72
```

### 4.4 控制生成深度

使用 `Shift + 鼠标滚轮` 调整生成平面的 Z 坐标：

```text
最小深度：0.25
默认深度：1.10
最大深度：2.60
单次步长：0.12
```

当前程序使用 GLFW/OpenGL 直接渲染，没有集成屏幕按钮或 ImGui 控件层，因此生成深度没有可点击按钮。调整深度时，终端会输出当前 `planeZ`；按住 `Shift` 后，画面中的预览泡泡会立即显示该深度对应的生成位置。

### 4.5 删除和数量限制

| 按键 | 功能 |
| --- | --- |
| `Shift + 右键` | 删除鼠标光标下距离相机最近的可见泡泡 |
| `,` | 减少运行时最大 live 泡泡数 |
| `.` | 增加运行时最大 live 泡泡数 |

删除使用相机射线与泡泡包围球进行拾取，并通过统一的 `RemoveBubble(...)` 同时清理该泡泡相关的接触关系、共享膜和融合表面。运行时默认上限为 8，硬上限为 16。

## 5. 风场与自由运动

### 5.1 无风状态

全局风默认关闭。无风时，泡泡不是完全静止，而是围绕各自的 `basePosition` 做有界低频摆动：

- 每个泡泡使用不同的相位和速度；
- 摆动目标随时间在 X、Y、Z 三轴变化；
- 弹性回拉保证泡泡不会不断积累单向位移；
- 融合后的泡泡也保持这种整体自由摆动，但融合表面本身不会重新变形。

### 5.2 风场控制

| 按键 | 功能 |
| --- | --- |
| `F` | 开启或关闭全局风 |
| `Q` | 降低风力强度 |
| `E` | 增加风力强度 |
| `I` | 风向向上 |
| `J` | 风向向左 |
| `K` | 风向向下 |
| `L` | 风向向右 |

风力强度范围为 `0.0` 到 `0.45`，单次调整步长为 `0.025`，默认保存的强度为 `0.16`。只有按 `F` 开启后，方向性风力才会作用于泡泡。

小泡泡具有更高的风力响应，大泡泡运动相对稳定。关闭风后，已有速度通过阻尼平滑衰减，泡泡逐渐回到有界摆动范围，不会突然停止。

## 6. 泡泡接触与结果选择

泡泡交互使用 `BubbleContactPair` 表示一对泡泡的接触关系。基本过程为：

```text
靠近
-> 预接触柔化
-> 短暂接触和压缩
-> 形成共享膜
-> 锁定一次接触结果
-> 分离 / 稳定 8 字双泡 / 融合
```

结果不会每帧重复随机。接触成熟后，系统根据以下因素计算概率并锁定一次结果：

- `min(radiusA, radiusB) / max(radiusA, radiusB)` 尺寸比；
- 接触持续时间；
- 共享膜厚度；
- 接触圆相对于小泡泡的尺寸；
- 法向碰撞速度；
- 当前风场扰动。

泡泡 ID 和当前场景代次种子共同生成稳定随机值，因此结果不会随帧率抖动。每次按 `X` 重置场景时，代次种子都会递增；同一轮接触的结果保持锁定，但下一轮重置不会让相同编号的泡泡永远得到同一个结果。

### 6.1 接触后分离

分离路径不会在首次碰撞时立即弹开：

1. 两个泡泡短暂压缩并形成共享膜；
2. 共享膜和接触圆逐渐收缩；
3. 粘结约束被释放；
4. 沿接触法线施加柔和分离速度；
5. 两个泡泡恢复独立运动。

接触面积较小或冲击较强时，分离概率会提高。

当前普通交互的分离概率限制在 `2%` 到 `8%`。减少的概率会落入稳定 8 字双泡结果，固定的 `G` 分离演示不受影响。

### 6.2 稳定 8 字双泡

尺寸接近的泡泡更倾向形成稳定 8 字双泡：

- 两个泡泡仍是独立腔体；
- 外轮廓形成 8 字形；
- 中间保留共享膜，而不是成为单腔花生形泡泡；
- 等尺寸时共享膜接近平面；
- 尺寸不同时，共享膜根据近似 Young-Laplace 压差 `1/rA - 1/rB` 产生弯曲；
- 接触圆有轻微周期波动，使双泡不显得完全静止。

### 6.3 融合

尺寸差越大，越倾向小泡泡并入大泡泡。融合过程为：

1. 共享膜逐渐变薄；
2. 接触膜局部破裂并扩大开口；
3. 外表面颈部扩张；
4. 两个外壳过渡为一张连续融合网格；
5. 融合网格被提升为幸存泡泡的持久表面。

融合中心采用体积加权：

```text
mergedCenter = (positionA * volumeA + positionB * volumeB) / (volumeA + volumeB)
```

最终半径保持体积守恒：

```text
mergedRadius^3 = radiusA^3 + radiusB^3
```

因此尺寸差较大时，最终中心更靠近大泡泡，小泡泡视觉上向大泡泡一侧被吸收。

## 7. 融合后的连续性

当前融合实现使用统一的表面渲染所有权：

- 泡泡外壳、共享膜和融合表面由 `BubbleSurfaceSystem` 管理；
- 融合完成后不会创建另一张球面替换融合表面；
- 完成前最后一帧使用的融合 `Model` 会直接成为幸存泡泡的 `Model`；
- 融合顶点保持世界尺度表示，模型矩阵只负责整体平移；
- 融合后的 GPU 网格不再进行自由泡泡顶点重算；
- 薄膜方向、膜厚、波长和颜色参数继续沿用原有渲染逻辑；
- 不使用 alpha 淡入淡出掩盖拓扑切换。

融合完成时保留两者按体积加权后的合速度。随后移除接触造成的持续单向驱动，让速度通过阻尼逐渐衰减，再进入有界摆动；如果开启全局风，融合泡泡仍可整体随风移动。

## 8. 三种交互演示

按 `G` 会重置双泡场景，并依次循环：

1. 等尺寸泡泡形成稳定 8 字双泡；
2. 小泡泡被大泡泡吸收并融合；
3. 短暂接触并形成共享膜后分离。

再次按 `G` 返回第一种场景。演示场景使用固定结果，便于观察视觉过程；用户动态生成的普通泡泡仍使用概率结果选择。

按 `X` 会重置为普通的同步多泡泡场景。

## 10. 主要实现位置

- `windows/main.cpp`：输入、生成、运动、风场、接触状态机、演示和渲染调度；
- `windows/simulation/display_bubble.h`：`DisplayBubble` 和 `BubbleContactPair` 状态数据；
- `windows/simulation/display_bubble_simulation.*`：体积、质量、接触索引和 broad phase；
- `windows/render/bubble_surface_system.*`：泡泡、共享膜和融合表面所有权；
- `windows/render/contact_geometry.*`：共享膜与融合网格生成；
- `windows/shader/shader_refraction.h`：折射、反射和薄膜干涉着色。

## 11. 当前限制

- 结果概率是面向实时视觉的经验模型，不是完整流体或膜排液求解器；
- 稳定双泡目前主要处理 pair-wise 共享膜，尚未实现 Plateau 三膜交线；
- 小泡泡吸收过程使用参数化融合网格，没有计算真实液膜质量传输；
- 多个泡泡同时融合时仍限制同一个泡泡只参与一条排他融合路径；
- 当前控制信息主要输出到终端，尚未制作屏幕 HUD。
